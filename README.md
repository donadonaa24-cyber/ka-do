# 遊戯王 一人回しシミュレーター

相手なしで、デッキの展開ルートを練習・記録するためのシミュレーター（ブラウザで動作）。

## 起動

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # ルールエンジンのテスト
npm run build    # dist/ に静的ファイルを出力（どこにでも置ける）
```

## できること

- **盤面**: メインモンスターゾーン×5、EXモンスターゾーン×2、魔法＆罠ゾーン×5、フィールドゾーン、デッキ・手札・墓地・除外・EXデッキ
- **ターン進行**: DP → SP → M1 → BP → M2 → EP。先攻1ターン目はドローなし・BPなし。2ターン目以降はドローして開始
- **召喚**
  - 通常召喚／セット（ターン1回）、アドバンス召喚（Lv5-6はリリース1体、Lv7以上は2体）、反転召喚
  - 特殊召喚（攻撃・守備・裏側守備）
  - 融合／シンクロ（チューナー1体＋レベル合計一致）／エクシーズ（同レベル・素材が重なる）／リンク（リンクモンスターは1か数値で数える）／儀式（レベル合計以上）
  - EXデッキからのリンクモンスターは「EXモンスターゾーン」か「リンク先」にのみ出せる。EXモンスターゾーンは1つまで（マスタールール 2020年4月改訂準拠）
- **魔法・罠**: 発動／セット。罠と、セットした速攻魔法はセットしたターンに発動不可。通常魔法などは「解決」で墓地へ。フィールド魔法は張り替えで古い方が墓地へ
- **自動処理**: EXデッキのモンスターは手札・デッキに戻らずEXへ／エクシーズ素材はモンスターが離れると墓地へ／トークンはフィールドを離れると消滅／PモンスターはフィールドからEXへ表側で
- **勝敗**: デッキ切れでのドロー、LP0で敗北。直接攻撃で相手LP（8000）を0にすると勝利（ワンキル練習用）
- **エンドフェイズの手札制限**（6枚）
- **練習機能**
  - シード指定（同じシード＝同じ初手・同じデッキ順）、初手指定
  - 全操作を記録。`Ctrl+Z` で1手戻す、「最初から」でやり直し
  - ルートの保存・読込（ブラウザに保存）、ログのコピー
  - 「効果発動（記録）」でカード名ごとの使用回数をカウントし、2回目以降は警告（ターン1制限の確認用）
  - 「ルールチェック」をオフにすると制限なしで自由に動かせる

## カード効果について

現時点ではカード固有の効果は自動処理しません。効果は「効果発動（記録）」でログに残し、サーチ・特殊召喚・墓地送りなどの処理は各カードのボタン（手札へ／特殊召喚／墓地へ…）で手動で行います。

## カードの追加

`src/data/` にカード定義（`CardDef`）とデッキ（`DeckList`）を追加し、`src/data/index.ts` に登録します。
書式は `src/data/testCards.ts`（動作確認用の架空カード）を参照。

## 構成

```
src/engine/   ルールエンジン（UIに依存しない純粋なTypeScript）
  types.ts    カード・盤面の型
  game.ts     アクション（召喚・発動・移動…）とルールチェック
  rules.ts    リンク先・素材計算などの判定
src/data/     カードデータ・デッキ
src/ui/       React の画面
```
